# 安全与访问

只有项目提供网络服务并需要选择或配置访问方式时才加载本文件。涉及凭据时同时读取 `secret-safety.md`。

## 交互式选择访问方式

只提供适用的选项：

- **SSH 本地端口转发**：仅授权 SSH 用户可用的临时私有访问。
- **公网 IP 和端口**：直接暴露，必须获得明确同意，并检查防火墙、认证和默认凭据。
- **域名和 HTTPS 反向代理**：适合长期运行的公网服务。
- **Cloudflare Tunnel**：使用公网域名，但不直接发布应用端口。

使用 SSH 本地端口转发时，将应用绑定到 loopback：

```text
ssh -N -L LOCAL_PORT:127.0.0.1:REMOTE_PORT user@host
```

修改 SSH 设置前检查实际生效配置。长期无人值守时优先使用受限账号和 SSH Key，不在记录中保存私钥内容。

## 公网入口

- 修改公网路由前运行 `preflight.sh ingress`。
- 确认 80/443 端口归属并复用唯一权威入口。
- 将上游应用绑定到 loopback 或私有 Docker 网络。
- 备份受影响的站点配置，测试通过后再 reload。
- 只有应用需要时才添加 WebSocket、上传大小或超时配置。
- 默认账号未处理、认证未确认、调试模式未关闭时，不开放公网。
- 管理后台优先限制来源、增加独立认证或保持私有访问。
- 随机路径、非标准端口和隐藏入口只能减少噪声，不能代替身份验证。
- 对扫描、截图、抓取、文件转换、构建、AI 推理或其他可消耗大量资源、访问任意目标的功能，确认应用自身认证、目标范围、内网/元数据访问边界、并发和限流；缺少内置保护时，在反向代理层增加认证或保持私有访问。

## Cloudflare 与 TLS

DNS 托管在 Cloudflare 且用户可提供受限 Token 时，优先使用 `acme.sh + Cloudflare DNS API + DNS-01`：

- 不依赖 80 端口；
- 申请和续签时无需停止 Nginx；
- 支持根域名和通配符证书。

Token 只授予目标 Zone 的 DNS Edit 和 Zone Read。Zone Token 足够时，不索取 Global API Key。

通常申请：

```text
example.com
*.example.com
```

`*.example.com` 只覆盖一级子域名。

将完整证书链和私钥安装到当前权威入口使用的路径。严格限制私钥权限，并为实际服务配置经过测试的 reload hook。

## 续签迁移

不要先删除现有证书或全局续签任务。先申请并安装替代证书，切换一个站点，完成外部验证，测试续签和 reload，然后只停用该域名已经被替代的任务。

## 外部服务

涉及 AI、支付、邮件、短信、DNS、对象存储或其他外部 API 时：

- 确认使用测试环境还是生产环境；
- 使用目标资源范围内的最小权限 Token；
- 说明可能产生的费用、额度和滥用风险；
- 使用不含用户数据和秘密信息的最小请求验证；
- 不因功能验证授权发布真实业务数据。

## 秘密信息规则

- 不提交或汇报 API Token、密码、私钥、Cookie、登录状态或 `.env` 值。
- 避免秘密进入 Shell 历史、进程参数、日志、截图和渲染后的 Compose 输出。
- 只验证凭据是否生效，不打印值。
- 秘密一旦进入对话、公开日志或 Git 历史，提醒撤销或轮换。
