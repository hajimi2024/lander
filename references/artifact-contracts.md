# 交接与部署记录

所有任务都在对话中交接。仅在同时满足以下条件时创建文件记录：

1. 选择服务路线；
2. 执行深度为标准或增强；
3. 目标是在环境中建立或维护超出一次性试运行生命周期的服务。

用户明确要求留档时可以例外创建。其他任务，包括轻量安装、CLI、导入和一次性试运行，不创建文件记录。

## 对话交接

状态只使用：

```text
成功 / 部分成功 / 阻塞 / 已回滚
```

始终说明采用路线、精确版本或镜像 digest、验证结果和使用方式。仅在适用时补充环境修改、撤销方法、组件、访问入口、持久化、证书、浏览器安全状态、资源余量和剩余风险。

脚本、面板或管理菜单项目按 `references/script-installer-handoff.md` 增加访问与管理交接。关键结果未验证时不得报告成功。

## 私有记录位置

默认保存到：

```text
$CODEX_HOME/deployment-records/<owner>--<repo>/<target>/
```

目标标签不包含密码、Token、连接字符串、IP 或域名。除非用户要求远程留档，不将记录同步到目标服务器。记录不得自动加入 Git 暂存区、提交、PR、Issue、Release、CI 制品或公开上传。

## 生命周期

- 用户确认标准或增强服务路线后，使用 `assets/templates/project-summary.md` 创建 `PROJECT_SUMMARY.md`。
- 第一次修改状态前，使用 `assets/templates/deployment-log.md` 创建 `DEPLOYMENT_LOG.md`，只追加有意义的阶段事件。
- 成功落地或在可恢复稳定节点暂停时，使用 `assets/templates/deployment-report.md` 创建或更新 `DEPLOYMENT_REPORT.md`。
- 只有真正发生回滚时才创建 `ROLLBACK_REPORT.md`。

无法安全创建记录时说明原因，并完成对话交接。

## 凭据与公开副本

私有报告只记录凭据来源、保存位置、文件权限、默认凭据处理状态、验证状态和轮换责任，不记录明文值。

用户明确要求公开分享时，保留私有原件并生成单独副本；删除 IP、主机名、账号、域名、内部路径、非必要端口、访问命令和秘密位置。发布前检查文件内容和 Git 差异。

完成标准：记录与实际状态一致，已验证和未验证范围分明，没有秘密值，也没有被自动公开。
