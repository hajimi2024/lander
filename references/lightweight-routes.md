# 轻量路线

仅用于安装、导入或一次命令即可完成，且不需要持续管理后台进程、状态或网络入口的任务。CLI、MCP 或本地工具需要长期托管时改走服务路线。

## 选择入口

优先顺序：

1. 官方稳定 Release 或便携制品；
2. 官方包管理器或安装命令；
3. 目标应用提供的导入或安装入口；
4. 只有用户需要修改源码或官方没有直接入口时才进入开发构建。

确认平台、架构、版本和安装范围。存在校验和或签名时验证；记录 Release、tag 或 commit。

## 执行

向用户说明安装位置、影响和移除方式。低风险单一操作可在一次确认后完成，不创建组件拓扑、部署日志或长期运维记录。

只修改任务需要的目录和配置。临时文件放在明确的隔离目录，完成后删除；不修改 PATH、全局包或其他共享环境，除非官方方式需要且用户已确认。

发现秘密、默认凭据、付费权限或生产配置时，额外读取 `references/secret-safety.md`，但不要因此加载服务器规则。

## 验证

- **Release 或便携程序**：文件完整、版本正确、能够启动并完成一个最小功能。
- **CLI 或包管理器安装**：命令可发现、版本正确、最小命令成功。
- **Skill、MCP、扩展或其他导入项目**：目标 Agent 或应用能够识别，并完成最小调用或功能检查。
- **一次性本机任务**：进程或命令按预期结束，输出可用，临时资源已处理。

完成标准：用户可以直接使用目标功能，已说明位置、版本、调用方式、验证结果和移除方法。未完成最小功能验证时报告“部分成功”或“阻塞”。
